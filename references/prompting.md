# 提示词与参考图

## 原意优先

默认原样发送用户提示词，不添加通用画质模板、不重新组织内容，不把失败恢复变成另一项任务。尺寸、质量、格式和模型由参数表达。

历史的修复、穿搭、特定衣物 / 场景等自动重写模板已移除。`--auto-retry` 只处理可恢复的请求失败，不改提示词、模型、质量或输出格式；明确拒绝时停止。

用户明确要求帮助编写提示词时，围绕动作、目标结果、必须保留的内容和必要排除项组织，不擅自扩展服装、饰品、背景或人物身份约束。

## 参考图

- 第一张图是实际编辑目标，其他图按用户指定用途使用。
- 一张参考图尽量只承担一个主要角色，明确哪些属性从哪张图延续。
- 支持最多 16 张输入图；本地图片和 data URL 必须先通过完整解码校验。
- `--manifest` / `input_images_manifest` 是诊断元数据，不自动改写提示词；不能替代对参考用途的明确描述。

例如，用户已经要求换背景并保留主体时，可描述：

```text
Edit image 1. Replace only the background with a plain clean light gray background. Keep the subject, clothing, pose, composition and lighting unchanged.
```

## 显式纯净背景模式

只有用户明确要求该模式时才启用 `--clean-background`。它将用户请求与“只改背景、保留主体、使用干净纯色背景”的约束一并发送。

“无背景”按纯色背景理解，不请求透明背景。Pillow 只校验文件，不承担去背或其他本地后处理。

## 恢复与验收

遇到限流、无账号、鉴权失败、文本驱动不支持或下载异常，先按错误类型处理，不自动修改提示词。真实生图完成后仍需目视验收，不能把 HTTP 成功、模型目录可见或文件可解码等同于内容正确。
